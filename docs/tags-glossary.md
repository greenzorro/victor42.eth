# Tag 词汇表

维护规范 tags 的人工定义和使用边界，确保一致性和可复用性。

本文件是人工维护的中文规范词表，管辖 `content/post/` 中文文章。英文文章的 tag 词表见 `tags-glossary-en.md`，两份词表独立维护、互不镜像；两种语言共用的 tag（如 `AI`、`Midjourney`）在两份词表各保留一份。每个 tag 只能出现一次；不同分类复用同一 tag 时，更新原条目的定义和使用边界，不新增重复条目。实际使用次数、文章列表和词表差异由 `docs/tags-stats.generated.md` 按语言分组自动生成。

## 格式说明

    ### `tag名`
    - **定义**：这个 tag 覆盖什么内容
    - **适用**：适合打在哪类文章上
    - **不适用**：容易误用但不该使用的情况
    - **同义/禁用**：不再使用的同义词、近义词或过细词

## 维护规则

- 新增 tag 前先查本文件，优先复用已有规范 tag。
- 不在本文件手动维护使用次数；使用次数以 `docs/tags-stats.generated.md` 为准。
- 一次性 tag 需要判断是否为值得保留的专名；如果不是，优先上卷到更通用 tag。
- 维护时检查重复条目、同义词分裂、过泛 tag、过细 tag。
- 维护 tags 时运行 `scripts/generate_tags_report.py` 更新自动统计报告。
- 词表按 tag 本身维护，不按分类分区。
