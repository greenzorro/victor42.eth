# Tag 词汇表

维护所有已使用的规范 tags，确保一致性和可复用性。

本文件是规范词表，不是批次流水账。每个 tag 只能出现一次；不同分类复用同一 tag 时，更新原条目的使用次数和定义，不新增重复条目。

## 格式说明

```
### `tag名`
- **定义**：这个 tag 覆盖什么内容
- **适用**：适合打在哪类文章上
- **不适用**：容易误用但不该使用的情况
- **同义/禁用**：不再使用的同义词、近义词或过细词
- **使用次数**：0
```

## 维护规则

- 新增 tag 前先查本文件，优先复用已有规范 tag。
- 使用次数只写最终数字，不写 `4+2=6` 这类过程算式。
- 一次性 tag 需要判断是否为值得保留的专名；如果不是，优先上卷到更通用 tag。
- 每批结束后检查重复条目、同义词分裂、过泛 tag、过细 tag。
- 词表按 tag 本身维护，不按批次或分类分区。

## 当前 QA 重点

- 复审只出现一次的非专名 tag，判断是保留、上卷还是删除。
- 复审过泛 tag：`日常`、`旅行`、`美食`、`科技`、`游戏`。
- 补充大部分条目缺失的「适用」「不适用」「同义/禁用」字段。
