和AI共同完成了一场客厅小改造，女儿和老婆赞口不绝。

## 突如其来的灵感和决心

起因是和前司的朋友聊天，聊到读书，朋友说她为此专门改造了客厅。我看完她家照片大受启发，现代人小家庭城市生活，到底需要什么样的客厅，在脑袋里一推演就会有答案。只是忙碌的成年人，很少能拿出勇气做点改变，让自己的生活变得更美好一点点。

不过，决心这个东西，说来就来的，不需要什么心理准备。我聊完立马从头推演了一遍，当天就开启客厅的改造计划。

我家已经装修完快10年了，费了许多心思，甚至换工作间隙花了几个月时间专门来搞这事：[一个设计师的装修笔记](https://victor42.eth.limo/post/interior/)

当时没小孩，也没想过会不会有。客厅初始设计服务两个成年人，沙发茶几电视柜，标准布局。这样的客厅，陪伴我和老婆度过了不少啃着鸡爪鸭脖看电影的周末。

![改造前堆满书籍玩具、衣服和健身椭圆机的杂乱客厅](https://cdn.victor42.work/posts/2026-07/0664ed725551bc8450bd3c00fcbd8708.webp)

自有女儿以来，客厅的作用早已偏离初衷。茶几电视柜变成玩具桌，沙发一半堆玩偶，一半堆阳台收进来又懒得叠的衣服。大人歇脚都在餐厅餐椅，很少在客厅。因为沙发虽舒服，但走进去很困难，找到地方坐下更困难。整个客厅成了小孩独自娱乐和家庭阅读的空间，但女儿玩具还是经常摆到过道上来，挡住去路。

本质是，客厅这个空间的注意力重心，从单一的电视，变成了多处分散的形式。即使没有小孩，城市小家庭的客厅，核心也早已不是电视了。没有客人，不看电视台节目，当代城市年轻人的客厅时光，要么给了手机平板，要么给了书，要么给了椭圆机瑜伽垫。当然，电视作为游戏机屏幕仍有一定地位，但不是必须。

这么看，硕大的组合沙发和茶几反而严重拉低了空间利用率。设施应为生活服务，让客厅顺应它的实际功能，并更好地承担这些功能：玩耍、阅读与亲子时光。同时也正式开辟一个家庭共同活动的空间，女儿之后会需要的，我自己也有不少书想在这读。

## 到底需要什么样的客厅

要回答这个问题，得从第一性原理出发，有个一定不会出错的思考顺序：

1. 梳理客厅的功能现状，并加入我们想要的额外功能。
2. 把这些功能对应到物品上，让每个需求都被满足。
3. 盘点所需物品，是不是都放得下，过于拥挤就要取舍。
4. 选定物品后，安排空间摆放。
5. 采购与实际改造。

前3步简单做个表就行了，客厅当前功能包括：

| 功能     | 现状          |
| :----- | :---------- |
| 小孩玩耍   | 电视柜、❌茶几、❌沙发 |
| 家庭阅读   | ❌沙发         |
| 投影仪播放  | 小边桌         |
| 大人歇脚   | -           |
| 书籍收纳   | 柱状书柜        |
| 玩具收纳   | 电视柜、❌茶几     |
| 杂物收纳   | 电视柜、小边桌、❌茶几 |
| 阳台衣物暂存 | ❌沙发         |
| 运动     | 椭圆机         |
| 睡觉     | ❌沙发         |
| 放松     | -           |

现有功能尽量保留，**大人歇脚**的功能我们希望恢复。另外还可以考虑引入新功能：放松，如果空间允许，加入按摩椅。

标出哪些功能需要特别增强。然后添置或换上空间利用率更高的物品，补上功能缺口：

| 功能     | 现状          | 新物品      |
| :----- | :---------- | -------- |
| 小孩玩耍   | 电视柜、❌茶几、❌沙发 | 矮书柜组     |
| 家庭阅读⏫  | ❌沙发         | 沙发床、单人沙发 |
| 投影仪播放  | 小边桌         | -        |
| 大人歇脚⏫  | -           | 沙发床、单人沙发 |
| 书籍收纳⏫  | 柱状书柜        | 矮书柜组     |
| 玩具收纳⏫  | 电视柜、❌茶几     | 矮书柜组     |
| 杂物收纳   | 电视柜、小边桌、❌茶几 | -        |
| 阳台衣物暂存 | ❌沙发         | 单人沙发     |
| 运动     | 椭圆机         | -        |
| 睡觉     | ❌沙发         | 沙发床      |
| 放松     | -           | 按摩椅      |

这里面关键的是矮书柜组，靠墙放一整排。书柜台面可以代替茶几作为玩具基地，内部大大提升客厅收纳能力。沙发床是另一个好东西，平时可坐下一大一小，读个绘本没问题，客人来了也能展开住几晚。组合沙发让出的地面也能摆玩具，客厅的可用空间会大许多，玩具不容易再侵占过道了。

盘点过后，发现独立的按摩椅可能是放不下，会吞掉女儿太多玩耍空间，但以后可以考虑买按摩靠垫。

到这里，要添置的物品已经基本敲定。硬装不太有必要动，只改软装就能达到目的。

## AI成了乙方改图狗

现在进入第四步，规划空间摆放。

![2016年装修时的房屋户型及房间家具布置的SketchUp三维模型图](https://cdn.victor42.work/posts/2016-08/08-02/2.png)

当年装修时，我把这一步做得非常细，非常重。我临时自学的SketchUp，然后就开始咔咔上手画立体图。我不是为了渲染出那种难辨真假的售楼处级效果图，我只想把所有物品的尺寸精确反映在一个模型里，尺寸精确到厘米级，判断摆不摆得下，怎么摆用起来最顺手。

虽然学习成本高，这套真的很管用，是室内布置的关键真相源。在这小小的客厅改造项目里，我也想用这种方式。只是SketchUp的操作我真是忘差不多了，我也不是职业室内设计师，没必要再重温这玩意。现在AI时代，这种简单几何形的立体建模，真的动动嘴就行。

![3D建模页面中展示的客厅空房间墙体及尺寸的三维模型](https://cdn.victor42.work/posts/2026-07/b72621ef448d7816dfa9dfb53bc4ea90.webp)

当年装修留下的尺寸测量记录，很多都能继续用，缺的少量数据临时量一下补上。然后，我把空间约束和基础尺寸信息，整理下发给AI，一轮输出就基本正确。再两三轮细节修正，空客厅就建模出来了：

> 这是一个南墙339cm、北墙281cm、东边阳台玻璃门333cm的梯形区域，东边两个角是直角，西边开放，通往餐厅。考虑东边窗帘的存在，实际可用面积可能还要减掉东边20cm宽。
> 
> 空间内有如下制约条件：
> 
> - 北墙中央有电源插座、网线口，所以路由器只能放在这里。
> - 其余的电源插座在空间的东北、东南、西南3个角。
> - 南墙有大面积墙纸，不适合直接投影。如果要投影，只能在北墙上，或者南墙加幕布。
> - 穿过客厅、通往阳台的通道，平行于北墙，距离北墙约40cm，宽至少需要80cm，不可被阻挡。

我让AI把空间分成了3层：底图、现状、计划，3层可以分别开关，方便我对比改造前后效果。

然后，我就开始像指挥乙方一样，告诉它沙发摆这里，椭圆机摆那里，茶几你画长点，圆柱书柜你画细点……作为一个曾经也被产品经理和运营指着屏幕让把按钮改红色、把卡片靠近2个像素的UI设计师，甚至有点心酸。

![暗色模式AI聊天界面，显示用户对家具尺寸信息的输入](https://cdn.victor42.work/posts/2026-07/d3dd0b4fc54d3ee91a0ff35484b5accb.webp)

![AI对话界面，显示用户调整沙发及椭圆机摆放位置的指令](https://cdn.victor42.work/posts/2026-07/cf1852d20cd06282163d6cd55b1e77c7.webp)

但是，不管怎样，经过了2晚的拉锯，AI漂亮地完成了任务。干这种活，就得用视觉能力强的AI，哪怕不用它看图，视觉能力强的模型对方位的理解也有明显优势。Antigravity 2.0，用起来确实指哪打哪。

![客厅现状的3D模型，显示家具集中摆放在南墙一侧](https://cdn.victor42.work/posts/2026-07/e2d3bad244302275f371ba7cf93bc964.webp)

完成后的立体图。这是现状，客厅除了那条通道，几乎无处下脚。

![客厅计划布局的3D模型，展示南墙一侧的整排矮书柜](https://cdn.victor42.work/posts/2026-07/5e45fcb7c29314fef2c30e32e05bbaa8.webp)

计划中的布局。椭圆机被放到了玻璃门边，餐厅和客厅间的一大视线障碍和动线障碍被移走。靠墙一排矮书柜，女儿玩具的主要基地。小边桌被书柜往外挤了些，所以改成南北向摆放，不挡通道。由于很少看投影仪，沙发床和单人沙发没必要对着北边电视墙，相对摆放更利于交谈。这些东西合围出一块开阔的游玩区，大型积木、拼图什么的都有地方玩了。

![客厅现状布局的3D俯视图，展示沙发茶几与电视柜的平面](https://cdn.victor42.work/posts/2026-07/0c19026bae60daa31a2c4e9d998e83bc.webp)

![客厅计划布局的3D俯视图，展示释放后的开阔活动区](https://cdn.victor42.work/posts/2026-07/6818e68d84679ca99c256cfd7fef5429.webp)

两张顶视图，更容易看出空间的明显释放。

其实到这里就可以了，改完什么样我心里有数。但为了让老婆和女儿能大概想象改造后的结果，我又让Codex读了这个项目，了解所有尺寸细节。再拍一张现状照片给它，用它的生图能力直接生成改造后的效果图。

![AI生成的客厅改造效果图，配有矮柜、单人椅和沙发床](https://cdn.victor42.work/posts/2026-07/f87971e2527edea8e1ea741f17f7f48b.webp)

大概是这么个意思，就是它把一些东西的细节样子给改掉了。另外，生图模型可能在训练时没怎么见过两个沙发在客厅中央隔空相对摆放，还是给我画成了常规摆法。

但问题不大，尺寸画得挺准确，就当是movie day的状态。家具还没有挑选，真要生成严谨的效果图，那应该在挑完家具后，把家具商品图也给它。既然一家三口脑子里都有画面了，这步就不必较真。

## 采购与完成

采购就没什么好说的了，花钱是最开心的，一天就买齐了。

东西全部收到后，一天搞定。上午请人搬走旧沙发茶几，下午老婆打扫屋子，我组装柜子和沙发，新客厅就成型了。

![改造完成后的客厅实拍，一名小女孩穿着黄裙在空地上奔跑](https://cdn.victor42.work/posts/2026-07/4044f3efc0f5148a100bd0aff5601c6f.webp)

女儿说，今天改造客厅真开心。靠墙那排书柜，有2个把手还是女儿帮忙装的。

画面右下的棕色单人沙发，感觉很不协调，靠背也不够高，坐着不舒服，就给退了。新的还在路上。

![摆满玩具的改造后客厅，阳光从阳台洒在整洁的瓷砖地面](https://cdn.victor42.work/posts/2026-07/594b8f39a3a79f4412426d4957bf6b3d.webp)

才过一天，女儿就迅速用她的玩具把这块空间填满了。为了防止女儿在金属书柜边角撞伤，上面还铺了一层桌垫，向外突出来1cm左右。

相比之前，确实松快多了。好几天后老婆都还在念叨，说这次客厅改造得真满意。

给生活一点点变化，生活也会给我们很多阳光。至于AI，谁说只能用来工作和赚钱呢？
